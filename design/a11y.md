# Accessibility baseline

Decided at phase 4, before implementation, because retrofitting accessibility means
rewriting components rather than adjusting them. Audited against this exact list in
phase 7 and the findings recorded — including the ones we fail.

Target: **WCAG 2.2 AA** for the flow in `plan/scope.md`.

## Contrast

Every pairing in `design/design-system.md` was chosen against the ratio, not the other way
round. Body text 15.8:1, secondary 9.1:1, the lowest text token 4.6:1, primary button 5.2:1.

- Text: ≥ 4.5:1. Large text (≥ 24px): ≥ 3:1.
- UI borders and focus indicators: ≥ 3:1 against their background.
- **Colour is never the only carrier of meaning.** Every status has a word or an icon as
  well — "Taken", "Confirmed", "Expired". A red chip that only says a number is a failure.

## Keyboard

The whole flow — pick an area, search, choose a bay, book, pay, read the code — must be
completable with keyboard alone.

- Logical tab order following visual order. No positive `tabindex`.
- **Visible focus ring** on everything focusable: `--focus-ring`. `outline: none` is only
  ever acceptable paired with a replacement indicator on the same rule — the codebase uses
  `outline: none; box-shadow: var(--focus-ring)` in three places, which is that pattern.
  Removing focus without replacing it is the thing forbidden here; the original wording said
  "never `outline: none`", which the implementation has always contradicted for a good
  reason
  without a replacement.
- Map pins are not a keyboard trap. **This changed in phase 7 and the baseline is corrected
  rather than the code.** The map was specified as `aria-hidden`; in practice Leaflet renders
  markers as focusable `role="button"` images and also makes the container focusable, so
  `aria-hidden` produced an `aria-hidden-focus` violation — a focusable element inside hidden
  content. The map is now a labelled `role="region"` with `keyboard: false` on the markers,
  which is honest about what a pannable map is. Every spot it shows is
  reachable from the list. This is why the map is an enhancement and never the only route.
- Escape closes any overlay; focus returns to whatever opened it.

## Screen reader

- Landmarks: one `<main>`, `<nav>` for the area picker, `<h1>` per screen.
- Inputs use real `<label>`, never placeholder-as-label. Placeholders vanish on typing and
  are invisible to some assistive tech.
- Errors are tied to their field with `aria-describedby` **and** announced via a polite live
  region — an error that is only red is invisible to a screen reader.
- Loading states announce: the skeleton carries `aria-busy="true"` and a polite
  "Searching…". Silence during a wait is indistinguishable from a broken page.
- The reference code has an `aria-label` that reads it character by character
  (`7 K 2 M…`), because "7K2M9QX4TB" read as a word is useless when someone is writing it
  down.

## Targets and input

- Minimum **44×44px** for every interactive target (`--tap-min`).
- Inputs at 16px minimum, so iOS Safari does not zoom on focus.
- Correct `inputmode` and `autocomplete`: `tel` for phone, `autocomplete="tel"`.
- Errors never clear what was typed.

## Motion

- `prefers-reduced-motion: reduce` removes all transitions and any skeleton shimmer.
- Nothing auto-plays, nothing moves without user action, no carousels.

## Language and copy

- `lang="en"` on the document.
- Plain English. "That bay was just taken", not "Booking conflict (409)".
- Times as `2:30 pm`, dates as `Tue 23 Sep` — the microcopy rules in
  `design/terminology.md`.

## Known gaps, stated up front

Honesty is worth more here than a claim of full compliance:

- **No screen-reader testing on a real device.** The audit in phase 7 is automated plus
  keyboard-only manual. NVDA/VoiceOver testing is not possible in the time.
- **The map is not fully accessible.** It is a labelled `role="region"` rather than
  `aria-hidden` (see Keyboard above), its markers are removed from the tab order, and
  duplicated by the list, which is the mitigation, not a fix.
- **No localisation.** English only, which is a real accessibility limit in Hyderabad where
  Telugu and Hindi are first languages for many drivers. Out of scope
  (`plan/scope.md`) and named here rather than quietly omitted.
